# Hackathon I – AI/Spec-Driven Book & RAG Chatbot Constitution

## Core Principles

### Accuracy & Source Fidelity
- All factual claims, explanations, or examples must be verifiable. Use primary sources wherever possible.
- Markdown content should be structured for clear citation and downstream RAG ingestion.

### Consistency & Formatting
- Maintain uniform formatting across all Markdown, code snippets, and Docusaurus pages.
- Follow naming conventions and file structure as defined by Spec-Kit Plus.

### Clarity & Readability
- Content should be accessible to advanced students familiar with AI and robotics.
- Text should be concise, instructional, and suitable for textbook style.

### Reproducibility
- All code, examples, and workflows must be reproducible using the provided instructions and tools.
- Any dependency or command referenced must be included or documented clearly.

### Integrity & Plagiarism-Free
- Zero-tolerance for unverified or plagiarized content.
- All references must follow proper citation rules (Markdown inline or as a references section).

### Phase-Oriented Workflow
- Follow the Hackathon I phases strictly:
  1. Constitution → 2. Specification → 3. Book Generation → 4. RAG Chatbot → 5. Optional Enhancements.
- Do not skip foundational steps; each phase must be completed before the next.

## Project Scope
- The project includes:
  1. AI/Spec-Driven Book Creation using Claude Code + Spec-Kit Plus.
  2. Minimal RAG Chatbot embedded in the book, answering questions from selected text.
- Optional features (bonus) like personalization, Urdu translation, or reusable subagents are not required for base points.

## Success Criteria
- Book runs on Docusaurus locally and is deployable via GitHub Pages.
- Chatbot answers questions correctly from the book text.
- Content complies with all principles above: accuracy, clarity, formatting, reproducibility, integrity.

## Governance
- All changes must go through local commit → branch → PR → merge workflow.
- Commit messages must be descriptive and reference the phase/feature:
  Example: "Phase A: Generated book chapter 1"
  Example: "Initial constitution commit"
- No manual edits outside the Spec-Kit Plus workflow unless reviewed and approved.
- AI-generated content must be verified against the constitution before committing.
